A big ol raytracing shader I've been working on for minecraft.
Runs in iris and completely native (and naive) openGl. Performance is questionable and the main feature is raytracing reflections and handheld lighting. This is not made for gameplay in the slightest, just a tech demo and learning experience for me.

Just download the compressed release file and put the .zip file into the shaders/ folder in minecraft for iris to find and select the shader to run it.
If you want to actually see any reflections, make sure to load up a labPBR supported pack (or even something like plain mirror) so then you can actually have the main reflection feature available.
